These exploratory results were generated before correcting the S669 mutation-site mapping. They only used 420 of 669 rows, incorrectly treating the mutation identifier's PDB/construct residue number as the 1-based sequence offset. The underlying labeled variants often have different sequence offsets. These files are preserved to make the failure auditable, but must not be cited as the current all-S669 benchmark. Run a corrected benchmark and update the paper before publication.
