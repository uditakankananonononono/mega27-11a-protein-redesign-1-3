\subsection{Inclusion rule and deduplication}
The committed \texttt{results/accession\_count.json} identifies accessions fetched and actually used for S669 graph construction, direct-mutation FireProtDB mapping, or archived disease wild/mutant comparison. Mere download does not qualify. S669 contributes 94 mapped structures and FireProtDB 74, with 11 accessions shared. The source records a 163-accession union once the disease comparisons are included; these are distinct PDB accession identifiers, not 163 independent test proteins or models. Table below is a checksum-level source ledger so that each physical input can be reidentified. The displayed 12-character SHA-256 prefix is a reading aid; the committed source JSON holds the complete SHA-256 for validation. No checksum itself establishes assay truth.
\subsection{Exact sequence overlap is a narrow control}
The committed \texttt{results/sequence\_overlap\_audit.json} records 69 distinct training sequences, 24 distinct test sequences and zero exact string overlaps (93 unique total). This check does not rule out homologs, near-duplicates or training overlap within the stored GeoDDG-Seq comparator. The fixed held-out negative comparison therefore remains the central result. The manifest does not substitute for protein-family blocking or a new external benchmark.
